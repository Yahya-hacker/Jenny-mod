================================================================================
CODE REVIEW FIXES
================================================================================

Issue 1: Initialization Loop
- Problem: init() called every tick via system.runInterval(1)
- Solution: Changed to single init() call on script load
- Impact: Prevents duplicate handler registration and spam messages

Issue 2: Invalid on_exit Commands
- Problem: /execute as @s run function reset_variant (Bedrock has no .mcfunction)
- Solution: Removed on_exit, rely on automatic state transitions
- Impact: Proper Bedrock Edition compatibility

Issue 3: Experimental Flag
- Problem: Entity marked is_experimental: false despite using Script API
- Solution: Changed to is_experimental: true
- Impact: Proper experimental feature declaration

Issue 4: Hard-coded Paths
- Problem: Absolute paths in Python scripts (/home/runner/...)
- Solution: Use Path(__file__).parent and sys.argv for CLI override
- Impact: Improved portability across systems
